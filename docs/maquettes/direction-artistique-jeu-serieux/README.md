# Direction artistique « jeu sérieux » : la rivière en coupe (retenue)

Direction retenue par le propriétaire le 27/11/2026 pour la refonte graphique. Elle cherche un juste milieu entre une application et un jeu vidéo sérieux, façon écran de sondeur : traits fins, chiffres en Barlow Condensed, texte en Barlow, une seule couleur d'action (ambre).

- Canevas en ligne (privé) : https://claude.ai/artifact/8deiq4eBjxpoQjPnY7fHHh
- Sources du canevas dans ce dossier (format Design `.dc.html`, à ouvrir dans le canevas, pas dans un navigateur seul) :
  - `Main.dc.html` : la rivière, l'écran Conseil (jour en thème clair, soir en thème sombre) ;
  - `Combo.dc.html` : le combo, détail du conseil et animation ;
  - `Boite.dc.html` : la boîte ;
  - `Spots.dc.html` : les spots ;
  - `Compte.dc.html` : compte et paramètres ;
  - `Kit.dc.html` : kit visuel (couleurs, typographie, pictogrammes, composants) ;
  - `canvas.json` : disposition du canevas et note de structure.

Structure : un seul écran sans défilement, la rivière vue en coupe. Le meilleur coup est posé à la profondeur où le pêcher ; les autres coups, les conditions et la réglementation sont à un tap. Une réglette choisit le moment. Boîte et Spots s'ouvrent depuis le dock, Compte depuis l'avatar.

À trancher avant le développement : les états chargement, hors ligne et erreur restent à dessiner ; certains textes sont des exemples (piège à éviter, étapes du geste, « Lac de Maine », températures des spots). Chaque user story de la refonte aura sa maquette HTML autonome (`.claude/rules/maquettes.md`).
