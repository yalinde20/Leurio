# Direction artistique « outdoor sobre » (proposition 1)

Maquette de direction artistique de la refonte graphique, appréciée par le propriétaire le 27/11/2026, mise de côté le temps d'explorer une seconde direction (« jeu vidéo »).

- Canevas en ligne (privé) : https://claude.ai/artifact/QA282bw5SFk2fz9CzhWZ5x
- Sources du canevas dans ce dossier (format Design `.dc.html`, à ouvrir dans le canevas, pas dans un navigateur seul) :
  - `Fondations.dc.html` : palette clair/sombre, typographie (Bricolage Grotesque + Inter), formes, pictogrammes des 5 familles, icônes, boutons, pastilles ;
  - `Main.dc.html` : écran Conseil, thème clair et thème sombre ;
  - `Etats.dc.html` : chargement, hors ligne (mode dégradé), hors des heures légales ;
  - `Boite.dc.html` : Boîte en clair et en sombre, Boîte vide.

Ce n'est pas encore la maquette d'une user story : une fois la direction choisie, chaque story de la refonte aura sa maquette HTML autonome (`.claude/rules/maquettes.md`).
